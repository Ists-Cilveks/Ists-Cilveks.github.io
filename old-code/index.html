Controls to try:
  • space: pause
  • WASD[]: move the camera
  • ↑←↓→: move cars
  • ←→: change multiplier
  • 1–9: change raster size
  • +-: change mandelbrot depth
  • LMBRMB: grab
  • X: toggle spinning or toggle antialiasing
  • R or double click: reload
